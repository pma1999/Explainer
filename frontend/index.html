API Key de OpenRouter Opcional

Si la configuras, podrás elegir modelos OpenRouter para el explainer en cada ejecución. En modo OpenRouter, segmentación, recorrido y recursos usarán DeepSeek V4 Flash vía OpenRouter, recursos usará búsqueda web, el OCR de PDFs usará Mistral nativo y el formateo usará DeepSeek V4 Flash vía OpenRouter. Obtén tu API key en openrouter.ai.

Solo podrás usar Gemini en el explainer.

✓ Configurada

API Key de DeepSeek Opcional

Si la configuras, podrás usar DeepSeek V4 Pro o DeepSeek V4 Flash directamente, sin OpenRouter. Los pasos auxiliares de este modo usan DeepSeek V4 Flash. Obtén tu API key en platform.deepseek.com.

No configurada

DeepSeek directo no estará disponible hasta guardar esta key.

✓ Configurada

DeepSeek directo queda disponible para PDF y URL web.

API Key de Tavily Necesaria para DeepSeek directo

En modo DeepSeek directo, el mapa de recursos usa Tavily Search para verificar recursos, autores, títulos y enlaces. Obtén tu API key en app.tavily.com.

No configurada

DeepSeek directo seguirá bloqueado hasta guardar esta key.

✓ Configurada

Tavily queda disponible para verificar recursos con DeepSeek.

API Key de Mistral Necesaria para PDF + OpenRouter/DeepSeek

Si quieres usar OpenRouter o DeepSeek directo sobre PDFs, el OCR nativo del documento lo hará Mistral. Obtén tu API key en console.mistral.ai.

No configurada

Los PDFs con OpenRouter o DeepSeek directo seguirán bloqueados hasta guardar esta key.

✓ Configurada

El OCR nativo de Mistral queda disponible para proyectos PDF con OpenRouter o DeepSeek.
